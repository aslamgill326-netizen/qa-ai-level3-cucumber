# Test design skill contract

Translate approved requirements into independent, risk-tagged Cucumber scenarios with preconditions, steps, expected outcomes, data and cleanup. Preserve assignment IDs in `docs/traceability.md`; report gaps rather than inventing behavior. Follow existing lowercase tags (`@ui`, `@api`, `@p1`, `@p2`) consistently unless the assignment explicitly requires other tags. Require review before adding scope. Provide a scenario-to-requirement matrix and note unverified assumptions.
